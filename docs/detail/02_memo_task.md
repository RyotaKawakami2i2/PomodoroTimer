# 詳細設計書: メモ・タスク機能

全体レイアウトの前提は [`00_common_layout.md`](00_common_layout.md) を参照（ブロック内コンテンツ幅は184px基準）。

## 1. 目的・概要

テキストベースのメモ帳とチェックボックス付きタスク管理を同一画面内に表示する。メモは複数作成・切替可能、タスクはドラッグ&ドロップで並べ替え、完了したタスクは自動的にリスト下部へ移動する。

## 2. 要素一覧

| 要素名 | 種別 | サイズ(px) | 配置 | 備考 |
|---|---|---|---|---|
| メモタブ列 | タブUI | 高さ22px、幅184px（収まらない分は2段目に折返し） | ブロック最上部 | 複数メモをタブで切替。タブ1つ最大幅60px |
| メモ追加ボタン | 小ボタン(+) | 18×18px | タブ列の右端 | クリックで新規メモタブを追加 |
| メモ本文入力欄 | `textarea` | 幅184px、高さ80px | タブ列の下 | 自由記述。入力停止500ms後に自動保存 |
| タスク入力欄 | `input[type=text]` | 幅150px、高さ24px | メモ本文の下 | Enterキーでも追加可能 |
| タスク追加ボタン | ボタン | 28×24px | タスク入力欄の右 | クリックでタスクを追加 |
| タスク行 | リスト項目 | 高さ24px、幅184px | タスク入力欄の下に縦積み | ドラッグハンドル14px＋チェックボックス16×16px＋テキスト＋削除ボタン16px |
| 完了取り消し線 | テキスト装飾 | - | タスク行内テキスト | `text-decoration: line-through` + 文字色を薄いグレーに変更 |

## 3. 複数メモの管理方式

- タブ切替方式を採用する（画面内に1つのメモ本文欄のみ表示し、タブで対象を切り替える）。
- タブをホバーすると右上に「×」アイコン（12×12px）が表示され、クリックでそのメモを削除できる。削除時は確認ダイアログ（`confirm()`）を表示する。
- タブの並び順はドラッグ&ドロップで変更可能とする（タスクの並べ替えと同じ仕組みを流用）。
- メモが1件もない状態は許可しない。最後の1件を削除しようとした場合は、空のメモ1件を残す。

## 4. タスクの並べ替え・完了処理

- 各タスク行左端のドラッグハンドル（≡アイコン, 14×14px）をつかんでドラッグすると、タスク間で順序を入れ替えられる（HTML Drag and Drop API、またはタッチ対応のため `pointerdown` ベースの自前実装を想定）。
- チェックボックスをオンにした瞬間、そのタスクは**未完了タスクの一番下・完了タスクの一番上**に自動移動し、取り消し線を表示する。
- 完了タスク同士の並び順は「完了した順（最新の完了が一番上）」を基本とする。
- 再度チェックを外すと、そのタスクは未完了タスクの一番下に戻る。
- タスクの削除: タスク行右端の「×」アイコン（16×16px、常時表示）をクリックして削除する。削除確認ダイアログは出さない軽量方針とする。

## 5. データ保存方針

- メモ・タスクともに、入力・並べ替え・チェック操作のたびに自動保存する（明示的な保存ボタンは設けない）。
- テキスト入力は連続キー入力のたびに保存せず、500msのデバウンスをかけてIndexedDBへ書き込む（頻繁な書き込みを避けるため）。
- チェック・並べ替え・削除等の操作は即座に保存する。

```
┌────────────────────────┐
│ [メモ1][メモ2][+]          │ ← メモタブ列
├────────────────────────┤
│ 本文入力エリア              │
│ (textarea, 複数行)         │ 高さ80px
│                          │
├────────────────────────┤
│ [新しいタスクを入力   ][+] │ ← タスク入力欄
├────────────────────────┤
│ ≡ ☐ 資料を作成する       × │ ← 未完了タスク
│ ≡ ☐ メールを送る        × │
│ ≡ ☑ ~~企画書を提出~~    × │ ← 完了タスク(下部・取消線)
└────────────────────────┘
```
