# 詳細設計書: タイマー機能

全体レイアウトの前提は [`00_common_layout.md`](00_common_layout.md) を参照（ブロック内コンテンツ幅は184px基準）。

## 1. 目的・概要

作業時間・休憩時間を交互にカウントダウンするポモドーロタイマー本体。時間はユーザーが変更可能で、初期値は作業25分・休憩5分。終了時はブラウザ通知で知らせる。

## 2. 要素一覧

| 要素名 | 種別 | サイズ(px) | 配置 | 備考 |
|---|---|---|---|---|
| モードラベル | テキスト | 高さ16px, 幅auto | ブロック上部中央 | 「作業中」/「休憩中」を表示 |
| 残り時間表示 | テキスト(大) | 高さ40px, フォントサイズ32px | ラベル下・中央 | `MM:SS` 形式 |
| 時間クリック編集エリア | クリッカブルテキスト | 残り時間表示と同一領域 | - | タイマー停止中のみクリックで直接編集可能（インライン編集） |
| 開始/一時停止ボタン | アイコンボタン | 32×32px | 時間表示の下・中央左寄り | 状態に応じて▶/⏸アイコンを切替 |
| リセットボタン | アイコンボタン | 28×28px | 開始ボタンの右隣（間隔8px） | 現在モードの設定時間に巻き戻す |
| モード手動切替リンク | テキストリンク/小ボタン | 高さ18px | 最下部 | 「休憩に切り替え」等、任意タイミングで作業⇔休憩を手動切替 |

ボタン2つ横並びの合計幅目安: 32 + 8(間隔) + 28 = 68px（コンテンツ幅184pxに対し十分収まり、中央寄せで配置）。

## 3. 状態遷移

```
[停止中(作業/初期値)]
     │ 開始ボタン
     ▼
[作業中カウントダウン] ──一時停止ボタン──▶ [作業一時停止中]
     │ 残り0になる                                │ 再開ボタン
     ▼                                            │
[作業終了→通知] ──自動遷移──▶ [休憩中カウントダウン] ◀──┘
                                     │ ⇄ 一時停止/再開
                                     │ 残り0になる
                                     ▼
                              [休憃終了→通知] ──自動遷移──▶ [作業中カウントダウン]（次サイクル）
```

- リセットボタン: どの状態からでも、現在のモード（作業/休憩）の設定時間に巻き戻して停止状態にする。
- 作業⇔休憩の自動遷移はユーザー設定に基づき無限に繰り返す（サイクル数の上限は設けない）。
- モード手動切替リンクにより、カウントダウンを待たずにいつでも作業⇔休憩を切り替え可能とする。

## 4. 時間変更の仕様

- 残り時間表示を停止中にクリックすると、分:秒がテキスト入力に切り替わり直接編集できる。
- 加えて設定・バックアップパネル（[`04_settings_backup.md`](04_settings_backup.md)参照）からも、作業/休憩それぞれのデフォルト時間を変更できる。
- 入力値の範囲: 1分〜180分（初期値: 作業25分・休憩5分）。範囲外・非数値の入力は無視し、直前の値を保持する。

## 5. 通知仕様

- 初回のタイマー開始操作時に `Notification.requestPermission()` を呼び出し、通知許可をリクエストする。
- 作業/休憩が終了した瞬間に、以下内容で通知を発行する。

| タイミング | タイトル | 本文 |
|---|---|---|
| 作業終了時 | 作業終了 | お疲れ様でした。休憩を始めましょう。 |
| 休憩終了時 | 休憩終了 | 作業を再開しましょう。 |

- 通知許可が得られていない場合は通知を送らず、ページ内表示のみとする（音声アラーム等の代替手段は本バージョンでは実装しない）。
- ブラウザが完全に閉じられている間は通知は届かない（`requirements.md` 記載の技術的制約どおり。タブ/ウィンドウが開いていれば、バックグラウンドでも通知可能）。
