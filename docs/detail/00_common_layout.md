# 詳細設計書: 画面共通・全体レイアウト

対象: アプリ全体の画面構成、共通の寸法・スタイルルール、レイアウトの土台となる仕様。個別機能の詳細は各ファイルを参照。

- [`01_timer.md`](01_timer.md) タイマー機能
- [`02_memo_task.md`](02_memo_task.md) メモ・タスク機能
- [`03_music_player.md`](03_music_player.md) 音楽プレイヤー機能
- [`04_settings_backup.md`](04_settings_backup.md) 設定・バックアップ機能

## 1. 対象画面一覧

| 画面/パネルID | 名称 | 表示方法 |
|---|---|---|
| MAIN | メイン画面 | 常時表示（通常ブラウザタブ内 または Document PiP小窓内） |
| SETTINGS_OVERLAY | 設定・バックアップパネル | フッターの設定アイコンをクリックすると、メイン画面の上にオーバーレイ表示 |

メイン画面は「通常のブラウザタブ/ウィンドウ表示」と「Document PiPによる常時最前面の小窓表示」の2状態を持つが、レイアウト・CSSは共通のものを使う（PiPは同一DOMを別ウィンドウへ移動させる仕組みのため、見た目は変わらない）。

## 2. 全体寸法

| 項目 | 値 | 備考 |
|---|---|---|
| 基準幅 | **200px** | 最小幅としても扱う。ブラウザの通常タブ表示でウィンドウを広げても、コンテンツ自体は200px幅の1カラムレイアウトを維持し中央寄せする |
| Document PiPウィンドウ初期サイズ | 幅200px × 高さ480px（たたき台） | `documentPictureInPicture.requestWindow({width:200, height:480})` で指定。ユーザーが後からPiPウィンドウをリサイズすることは可能 |
| 高さ | 固定しない | コンテンツ量に応じてページ全体が縦スクロールする |

## 3. 共通スタイルルール（たたき台）

| 項目 | 値 | 備考 |
|---|---|---|
| 基本フォントサイズ | 12px | 200px幅に収めるため小さめに設定 |
| 見出しフォントサイズ | 13〜14px | 太字 |
| 行間 | 1.4 | |
| ブロック内側の余白(padding) | 8px | 上下左右共通。コンテンツ実効幅は 200 − 8×2 = **184px** となる（各詳細設計書のpx値はこの184pxを基準にする） |
| ブロック間の余白(margin) | 6px | 縦に並ぶブロック同士の間隔 |
| 角丸 | 4px | ボタン・カード共通 |
| 配色 | 未確定（実装時に決定） | ライト基調1色で統一し、`--color-bg` `--color-text` `--color-accent` 等のCSS変数で管理する方針のみ本設計で定める。ダークモード切替は本バージョンの対象外 |

## 4. ブロック構成とおおよその高さ配分（たたき台）

上から下へ、以下の順で縦に並べる。

| 順 | ブロック | 高さ目安 | 備考 |
|---|---|---|---|
| 1 | タイマーブロック | 約150px | 常時表示・折りたたみ不可 |
| 2 | メモ・タスクブロック | 約220px〜（可変） | 内容に応じて伸びる |
| 3 | 音楽プレイヤーブロック | 約140px〜（可変） | プレイリスト展開時は伸びる |
| 4 | フッター（設定アイコン） | 約32px | 常時最下部 |

初期表示高さ目安: 150 + 220 + 140 + 32 ≒ **542px**。PiP初期高さ480pxからは一部はみ出す想定のため、PiP表示直後から縦スクロールが発生する前提とする。

並び順の意図: ポモドーロタイマーが主機能のため最上部に配置し、次いで作業中に使うメモ・タスク、息抜き用の音楽プレイヤー、最後に使用頻度の低い設定を配置する。

## 6. Document PiP表示時の挙動

- フッターまたはヘッダーに「PiPで表示」ボタン（アイコン, 20×20px）を配置し、クリックすると `documentPictureInPicture.requestWindow()` でメイン画面のDOMをPiPウィンドウへ移動する。
- PiP非対応ブラウザ（Firefox/Safari等）では、このボタン自体を非表示にする（機能検出: `'documentPictureInPicture' in window`）。
- PiPウィンドウを閉じると、DOMは元のタブ内へ自動的に戻る（Document PiP APIの標準挙動）。

## 7. スクロールルール

- 横スクロールは発生させない（`body`に`overflow-x: hidden`を指定）。
- 縦スクロールのみ許可する（`overflow-y: auto`）。
- 各ブロック内に個別のスクロール領域は作らず、ページ全体で1本のスクロールバーに統一する（メモ本文やタスク一覧、プレイリストが増えてもブロック内スクロールにはしない）。
