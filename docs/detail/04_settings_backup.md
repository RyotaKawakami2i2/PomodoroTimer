# 詳細設計書: 設定・バックアップ機能

全体レイアウトの前提は [`00_common_layout.md`](00_common_layout.md) を参照（ブロック内コンテンツ幅は184px基準）。

## 1. 目的・概要

タイマーの作業/休憩時間の変更、および全データ（設定・メモ・タスク・プレイリスト）のバックアップ書き出し・読み込みを行うための設定パネル。常時は非表示で、フッターの設定アイコンから開閉する。

## 2. 要素一覧

| 要素名 | 種別 | サイズ(px) | 配置 | 備考 |
|---|---|---|---|---|
| 設定アイコン(フッター) | アイコンボタン | 24×24px | メイン画面フッター中央 | クリックでオーバーレイパネルを開く |
| オーバーレイパネル本体 | パネル(モーダル的) | 幅200px(メイン画面と同幅), 高さauto | メイン画面全体に重ねて表示 | 半透明の背景＋前面にパネル。パネル外クリックで閉じる |
| 閉じるボタン | アイコンボタン | 20×20px | パネル右上 | ×アイコン |
| 作業時間設定 | ラベル＋数値入力 | 入力欄: 幅50px、高さ22px | パネル上部 | 単位「分」、範囲1〜180 |
| 休憩時間設定 | ラベル＋数値入力 | 入力欄: 幅50px、高さ22px | 作業時間設定の下 | 単位「分」、範囲1〜180 |
| バックアップ書き出しボタン | ボタン | 幅184px、高さ28px | 時間設定の下 | クリックでJSONファイルをダウンロード |
| バックアップ読み込みボタン | ボタン(ファイル選択) | 幅184px、高さ28px | 書き出しボタンの下 | `input[type=file]` をクリックで起動、`accept=".json"` |
| 確認ダイアログ | ブラウザ標準 `confirm()` | - | - | 読み込み実行前に「現在のデータを上書きします。よろしいですか？」を表示 |

## 3. 開閉挙動

- フッターの設定アイコンをクリック → パネルがメイン画面の上にフェードイン表示（アニメーション200ms程度、任意）。
- パネル背景の半透明オーバーレイ、またはパネル右上の×ボタンをクリックするとパネルを閉じる。
- パネルが開いている間、メイン画面側の操作（タイマー等）は一時的に無効化する（背面クリック不可）。

## 4. タイマー時間設定

- 作業時間・休憩時間をそれぞれ数値(分)で入力し、変更は即座に反映・保存される（「保存」ボタンは設けず、入力欄からフォーカスが外れたタイミングでIndexedDBに保存）。
- 現在カウントダウン中のタイマーには影響を与えず、次回のサイクルから新しい設定値が適用される。
- 変更後もタイマーブロックの「時間クリック編集」（[`01_timer.md`](01_timer.md)参照）でその場限りの時間に一時変更することは別途可能。

## 5. バックアップ書き出し仕様

- 書き出しボタン押下時、IndexedDB内の全データ（`settings`, `memos`, `tasks`, `playlist` の4ストア）を1つのJSONオブジェクトにまとめ、`Blob` 化して以下のファイル名でダウンロードする。
  - ファイル名例: `pomodoro_backup_YYYYMMDD_HHmmss.json`
- JSON構造案:

```json
{
  "version": 1,
  "exportedAt": "2026-09-15T12:00:00.000Z",
  "settings": { "workMinutes": 25, "breakMinutes": 5 },
  "memos": [ { "id": "...", "title": "...", "body": "...", "order": 0 } ],
  "tasks": [ { "id": "...", "text": "...", "done": false, "order": 0 } ],
  "playlist": [ { "id": "...", "videoId": "...", "title": "...", "order": 0 } ]
}
```

## 6. バックアップ読み込み仕様

- 読み込みボタン押下 → ファイル選択ダイアログ → JSONファイルを選択 → 内容をパースし、`version` フィールドの存在と各ストアの配列形式を簡易バリデーションする。
- バリデーションNG（JSON構文エラー、`version`フィールドなし等）の場合: 「ファイルの形式が正しくありません」とエラー表示し、既存データは変更しない。
- バリデーションOKの場合: 確認ダイアログ（既存データを上書きする旨）を表示し、OKなら現在のIndexedDBの内容を読み込んだ内容で全て置き換える。
- 読み込み完了後、画面を再描画（またはリロード）して反映する。
